# 📖 About

**Desktop Calculator** is a small graphical calculator written in **Python** using the built-in **Tkinter** library.

The app opens a fixed-size window with a large display, number buttons from `0` to `9`, the four basic operators (`+`, `-`, `*`, `/`), an equals button, and an **AC** button that resets the screen.

It is designed as a clear example of object-oriented GUI programming: one `Application` class builds the layout, handles button clicks, evaluates the expression, and shows the result.

> **Tagline:** *A simple desktop calculator built with Python and Tkinter for learning GUI basics and everyday arithmetic.*

---

# ✨ Features

* 🧮 Addition, subtraction, multiplication, and division
* 🔢 Number pad from `0` to `9`
* 📺 Large right-aligned display
* 🟡 Equals button (`=`) to calculate the current expression
* 🧹 All Clear (`AC`) to reset the display to `0`
* 🎨 Soft teal and yellow color theme
* 🪟 Fixed window size so the layout stays tidy
* ⚠️ Friendly message when the expression is invalid
* 📦 Single file — no extra packages required
* 🖥️ Runs on Windows, macOS, and Linux (with Python + Tkinter)

---

# ⚙️ How It Works

1. Each number or operator button adds its symbol to the current expression.
2. The display updates immediately after every click.
3. Pressing **`=`** reads the expression and evaluates it.
4. A valid result appears on the screen and can be used in the next calculation.
5. If the expression is not valid, the display shows `Invalid Syntax!`.
6. Pressing **`AC`** clears everything and puts `0` back on the screen.

# ▶️ How to Run

### Requirements

* Python 3
* Tkinter (included with most Python installations)

### Run the app

```bash
python Calculator.py
```

On some systems you may need:

```bash
python3 Calculator.py
```

If Tkinter is missing on Linux:

```bash
sudo apt install python3-tk
```

Then run the file again.

# 📁 Project Structure

```text
.
└── Calculator.py    # Main calculator window and logic
```

The whole project lives in one file:

* `Application` — main window, buttons, and calculator logic
* `buttonClick()` — appends numbers and operators
* `CalculateTask()` — evaluates the expression
* `ClearDisplay()` — resets the screen
